# Lyrixis Publisher Desk

Apixis Dev LLC · lyrixis@apixis.dev

## One sentence
A rights holder (Amazon, a house, an author) **hires Lyrixis**. They **hand us a library they already own**. We return timed audio + aligned text. We never pull a store.

## Not this product
- Kindle / Audible / any store scrape
- Pretending Amazon is already a customer
- Selling Cixy’s native voice
- Celebrity clones

## This product
1. Contract + rights attestation (their counsel, our counsel).
2. They deliver: epub/pdf/docx + metadata (title, ISBN, language, territory).
3. They pick voices from the Lyrixis floor or bring a licensed voice.
4. We produce: chapter audio, word timings, QC report.
5. We deliver files to their bucket or our `/listen` if they want hosting.
6. Money: enterprise invoice **or** Wallet XP (Empire pack and up). No second card form on Lyrixis.

## Build order
Phase A (now)
- `/voices` rotating floor
- `/listen` public-domain demo
- `/publishers` one-pager + lead form
- This blueprint

Phase B
- Upload drop for attested manuscripts (private bucket)
- Job row: ingest → normalize → TTS → align → QC
- Wallet SKU `lyrixis.listen.hour` + `lyrixis.voice.<id>`

Phase C
- Publisher dashboard: titles, minutes produced, rejects
- 70/30 voice-owner split on marketplace voices
- Optional publisher rev share on hosted listens

Phase D
- Named-house pilots only after a signed SOW (Amazon would be this phase, not a homepage claim)

## Pricing sketch (not a quote)
- Demo / sample chapter: 1,000 XP
- Production hour: priced per SOW after we know language + QC level
- Hosting listen: XP per finished hour, Wallet only

## Legal gates
- Written license or work-for-hire from the rights holder before any TTS job starts
- Voice talent consent on file
- No title on `/listen` without a rights row
