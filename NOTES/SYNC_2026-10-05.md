## DECISIONS D1–D17 IN MY OWN WORDS (verification)

1. **D1 (Ixis never expire):** Paid Ixis have no expiry timestamp anywhere. Never add one. Bonus Ixis may expire in the future but not enforced yet.
2. **D2 (Monthly seats last 30 days):** Ixis themselves don't expire, but access bought with them does. A monthly seat renews_at = capture time + 30 days, and they stack. One-time unlocks last forever.
3. **D3 (No refunds, all sales final):** No cash back. If someone bought 10k Ixis and spent 8k, they keep 2k to spend. Stripe refunds are not issued. If a refund is forced (chargeback lost), the webhook removes the Ixis (balance can go negative). Checkout shows FINAL_SALE_NOTICE.
4. **D4 (One shared Apixis login):** Every family site uses Apixis ID via /sso/authorize + /api/sso/token. The Wallet Supabase project is the identity provider. Sites verify tokens instead of trusting owner_email directly.
5. **D5 (Legal record of every transaction):** Migration 008 `audit_events` logs every purchase, refund, reserve, capture, release with time, date, site, transaction ID, invoice/receipt, IP. Master accounts can export via GET /api/admin/audit.
6. **D6 (Ownership split):** Awad owns design/UI; Claude (backend lead) owns backend/plumbing.
7. **D7 (Claude is family lead):** Claude is the lead developer for all Apixis family repos (backend and plumbing).
8. **D8 (Apixis Family Company is its own economy):** Ixis is platform credit now, becomes crypto once compliant. One shared Wallet and ledger across every app, never per-site balance. The ledger maps onto the future coin.
9. **D9 (Every site links Buy Ixis):** buyIxisUrl(app, returnUrl) sends user to Wallet, they buy, return to same site with Ixis. Every catalog app is valid destination; return host must be allowlisted.
10. **D10 (No clones, no duplicates):** One Wallet, one SDK. Sites carry copies of sdk/*.ts and never fork them. Change the SDK in ApixisWallet, then copy to sites.
11. **D11 (Starter in-world Ixis = 1,000):** First Apixis ID sign-in grants 1,000 in-world Ixis (Awad lock 2026-09-29, confirmed 2026-09-30). Docs that said 200 are wrong.
12. **D12 (Apixis Bank fee = 5% everywhere):** No per-site fee. Ominix moved from 8% to 5%. Fee math lives with the product that sells, but the number is family-wide (500 bps).
13. **D13 (Ominix is Ixis-only):** NXC wallet/ledger retired (deactivated, not deleted). Ominix orders go through Wallet reserve+capture like every other site.
14. **D14 (Non-Wallet Stripe paths deactivated):** Contraxis, Socixis Stripe webhooks return 410. Only Wallet runs Stripe for Ixis. Exceptions: qahwahworld physical-coffee Stripe (D14 itself) and Pinixis (D17).
15. **D15 (One log, one board per repo):** AI_CHANGELOG.md is the only change log per repo. docs/FAMILY_STATUS.md (ApixisWallet) is the only family status board. Per-repo NOTES/*.md, JUNOAI_NOTES, WORKBOARD, LAUNCH_NOTES are archives — don't update or create new ones.
16. **D16 (verifyOtp type: "email" everywhere):** GoTrue mints `signup` token for never-seen email, `magiclink` for known. `type: "magiclink"` rejects signup tokens (otp_expired). `type: "email"` accepts both. Fixed in callback and SDK; copy the kit, never patch by hand.
17. **D17 (Pinixis Stripe exception):** Pinixis takes card payments through its own Stripe (deposits, marketplace Connect sellers). Second exception to D14 after qahwahworld. Ixis stay Wallet-only.
